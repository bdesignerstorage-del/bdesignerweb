# BDesigner Public Web Frontend

This folder intentionally contains only the preserved BDesigner public homepage,
public project-detail screen, their shared visual shell, and the existing
login/create-account modal.

Legacy ERP, Admin, PM, Civil Engineer, Brand Partner, marketplace, package,
payment, BOQ, CRM and other feature UIs were removed from this clean baseline.

## Run

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

API calls use the same-origin `/api` base path.
